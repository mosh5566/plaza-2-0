מה זו בכלל אפליקציה?

דמיין מחברת קסם ענקית ⚡ — לכל אחד בעולם יש עיפרון, וכולם יכולים לכתוב ולקרוא באותה מחברת בו-זמנית.

אבל המחברת לא נמצאת אצלך — היא נמצאת במקום מיוחד באינטרנט, וכל הדפדפנים והטלפונים בעולם יכולים לפתוח אותה.

פרק 1 — מאפס

ממה אפליקציה בנויה? 🧱

בדיוק כמו מסעדה. 3 חלקים שעובדים ביחד:

🪟1. ויטרינהמה שאתה רואה: הכפתורים, הטקסט, התמונות.
זה ה"חזית" (Frontend)
👨‍🍳2. מטבחהמוח של האפליקציה: מקבל בקשות, מבשל תשובות.
זה ה"שרת" (Backend)
🧊3. מקררשומר את כל המידע — משתמשים, פוסטים, הודעות.
זה ה"מסד נתונים" (DB)
דוגמה: אתה לוחץ "פוסט חדש" בוויטרינה → המטבח מקבל את התוכן → שם אותו במקרר → מאשר חזרה לוויטרינה → כל המשתמשים בעולם רואים את הפוסט החדש.

פרק 1 — מאפס

איפה האפליקציה חיה? ☁️

בענן — לא בעננים בשמיים אלא במחשבי ענק של חברות גדולות בעולם.

🏢חוות שרתים

בניין ענק עם אלפי מחשבים שדולקים 24/7. ממוזג, מאובטח, עם חשמל גיבוי

🤝חברות שמשכירות

אמזון (AWS), גוגל, מיקרוסופט, Render — מוכרים לנו "פיסת מחשב" בחודש

🌎גישה מכל מקום

כל מי שיש לו אינטרנט — בארץ, ביפן, בארה"ב — יכול להיכנס לאתר שלך

שלנו ספציפית: השרת חי על מחשב של חברת Render בארה"ב. לוקח לו ~150ms להגיע אליך בישראל.
פרק 2 — שלנו

ממה פלאזה בנויה? 🔧

החלקים שעובדים יחד כדי שתעבוד:

🪟
HTML + CSS + JavaScript (חזית)כל מה שאתה רואה בדפדפן — הפיד, הצ'אט, ההרשמה. קובץ אחד גדול של 145KB.
👨‍🍳
Node.js + Express (שרת)המוח של הפלטפורמה. JavaScript שרץ במחשב באינטרנט, מקבל בקשות מהדפדפן ועונה.
🧊
SQLite (מסד נתונים)קובץ אחד שמכיל את כל המשתמשים, הפוסטים, הצ'אטים. פשוט אבל מספיק עד 1,000 משתמשים פעילים.
⚡
Socket.io (זמן אמת)קסם שגורם לצ'אטים להופיע מיד אצל כולם — בלי שצריך לרענן את הדף.
📱
PWA (גרסה למובייל)מאפשר התקנה כאפליקציה רגילה על טלפון — בלי לעבור דרך החנות.

פרק 3 — מה עברנו

מה עשינו עד היום ✅

שלב 1: דמו קונספט

בנינו אב-טיפוס HTML יחיד — להוכיח את הרעיון של "אין אלגוריתם, הכל נעלם תוך 24-48 שעות"

שלב 2: 30+ פיצ'רים

פיד, חדרי צ'אט, פרופילים עסקיים, תרגום, מיקום, הקלטות, וידאו, סקרים — הכל לחיץ ועובד

שלב 3: Backend אמיתי

שרת Node.js + SQLite + Socket.io עם 30+ endpoints — הרשמה, פוסטים, צ'אטים, אדמין

שלב 4: חיבור חזית ↔ שרת

החזית עברה ממצב "דמו עם localStorage" ל"מצב LIVE" — נתונים אמיתיים נשמרים

שלב 5: פריסה לענן

הקוד עלה ל-GitHub → נפרס ב-Render → URL ציבורי חי 24/7

שלב 6: גרסה למובייל (PWA)

מניפסט + Service Worker + אייקונים → אפשר להתקין כאפליקציה רגילה בטלפון
